# ZCode Mobile

Unofficial Android remote client for ZCode Desktop.

This preview renderer supports **Markdown**, `inline code`, and basic structure.

## What this app does

- Scan or paste a ZCode Remote URL
- Open the official Remote Control page in a WebView
- Send voice transcripts back to the desktop agent
- Preview artifacts produced by the agent
